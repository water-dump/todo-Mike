# 민규의 할 일 목록 (Mike's todo list)

할 일을 적고, 마감일을 정하고, 하나씩 끝내 가는 웹 할 일 목록이에요.
할 일은 Supabase 데이터베이스에 저장돼서 새로고침해도, 다른 기기에서 열어도 그대로 남아 있어요.

👉 웹사이트: https://todo-mike-iota.vercel.app

## 주요 기능

- **할 일 관리**: 추가, 고치기, 지우기, 완료 체크
  - ✏️를 누르거나 글자를 더블클릭하면 내용과 마감일을 고칠 수 있어요.
  - Enter나 ✅로 저장하고, Esc로 취소해요.
- **작성자 이름 (선택)**: 할 일마다 누가 적었는지 남길 수 있어요. 목록 오른쪽에 동그란 이름표로 보여요.
  - 이름 칸에 적은 이름은 브라우저가 기억해서 새로고침해도 남아 있어요.
- **마감일 (선택)**: 날짜를 정하면 할 일 아래에 `📅 10월 15일 · D-5`처럼 보여요.
  - 마감이 지난 할 일은 날짜가 빨간 글씨로 보여요.
  - 오늘 마감인 할 일은 빨간 테두리와 🔥 "오늘 마감!" 이름표로 강조되고, 목록 위에 경고 배너가 떠요.
  - 내일까지인 할 일은 분홍 글씨로 보여요.
  - 완료한 할 일에는 경고를 띄우지 않아요.
- **정렬**: 진행 중인 할 일이 위, 완료한 할 일이 아래에 모여요. 각 묶음 안에서는 마감이 가까운 순서이고, 마감일이 없는 할 일은 아래쪽이에요.
- **탭**: 전체, 진행 중, 완료 중에서 골라 볼 수 있어요. 고른 탭은 브라우저가 기억해요.
- **달성률**: 남은 할 일 개수와 달성률을 진행 막대와 함께 보여줘요.
- **오류 표시**: 저장에 실패하면 화면에 이유를 보여주고, 바꾼 내용을 원래대로 되돌려요.

## 사용한 기술

| 기술 | 하는 일 |
|---|---|
| HTML, CSS, JavaScript | 화면과 동작 전부. 따로 설치하거나 빌드할 게 없어요 |
| [Supabase](https://supabase.com) | 할 일을 저장하는 데이터베이스 |
| [supabase-js](https://supabase.com/docs/reference/javascript) | 브라우저에서 Supabase와 주고받는 라이브러리 (jsDelivr에서 불러와요) |
| [Vercel](https://vercel.com) | 웹사이트 배포 |

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 앱 전체 (화면, 디자인, 동작) |
| `config.js` | Supabase 주소와 publishable key |
| `.mcp.json` | Claude Code가 Supabase에 연결하기 위한 설정 |
| `hello.txt` | 처음 만든 연습용 파일 |

## 데이터베이스 구조

Supabase의 `todos` 표에 할 일 하나가 한 줄로 저장돼요.

| 칸 | 종류 | 설명 |
|---|---|---|
| `id` | 숫자 (자동 증가) | 할 일 번호 |
| `text` | 글자 | 할 일 내용. 비워둘 수 없어요 |
| `done` | 참/거짓 | 완료했는지 여부. 처음에는 거짓(false)이에요 |
| `author` | 글자 (선택) | 작성자 이름. 1~20자예요 |
| `due_date` | 날짜 (선택) | 마감일 |
| `created_at` | 날짜와 시각 | 만든 시각. 자동으로 들어가요 |

## 보안 안내

> ⚠️ **이 앱은 로그인 없이 누구나 할 일을 읽고, 추가하고, 고치고, 지울 수 있어요.**

- `todos` 표에는 RLS(행 단위 보안)가 켜져 있어요. 다만 읽기, 추가, 고치기, 지우기를 모두 누구에게나 허용하는 정책이 걸려 있어요.
- 친구들과 함께 쓰는 연습용 목록이라 일부러 이렇게 열어 뒀어요. 남이 보거나 지우면 안 되는 내용은 적지 마세요.
- `config.js`의 **publishable key**는 웹페이지에 공개하라고 만든 키라서 보여도 괜찮아요.
- **secret key, 비밀번호, `service_role` 키는 절대 저장소에 커밋하면 안 돼요.** 이 사이트는 저장소의 파일을 그대로 인터넷에 올려서, 커밋한 파일은 누구나 주소로 열어볼 수 있어요. 이 README.md도 마찬가지예요.
